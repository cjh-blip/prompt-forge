# Prompt Forge

> 在向任何 Agent 提出任务之前，先把模糊想法翻译成对方能最大化产出的结构化指令。

## 这是什么

一个 Hanako Agent skill，基于两套完整资料（提示工程公选课 7 份课件/实验 + DeepSeek 使用指南 18 份 PDF）从第一性原理出发设计。

不做提示词模板堆砌——做的是**需求翻译**：把用户脑子里未结构化的原始想法，通过对话自然转化成目标 Agent 能最大化产出的 prompt。

## 核心框架

**ICE 三要素**：指令（Instruction）+ 上下文（Context）+ 期望（Expectation）

**五类 Agent 适配策略**：

| Agent 类型 | 策略 |
|-----------|------|
| 推理优先型（DeepSeek R1） | 给边界条件，少给步骤，留推理空间 |
| 指令跟随型（GPT-4/Claude） | 给清晰步骤，结构化格式，少歧义 |
| 多模态/文生图型 | 给风格参考、场景描述、负面提示词 |
| 代码型（Cursor/Copilot） | 给输入输出规格、边界条件、测试用例 |
| 写作/内容型 | 给语气、结构、示例、角色设定 |

**四阶段工作流**：需求解析 → Agent 适配 → 生成 Prompt → 自检 & 迭代建议

## 源材料

- `大模型与提示工程` 公选课（1 份核心课件 + 3 份实验 + 2 份专题课件）
- `raw/deepseek/` 18 份使用指南 PDF（文本可读约 10 份，图片扫描约 8 份，内容重叠）
- 完整分析见：`wiki/ai/deepseek-r1-analysis.md`（第一性原理底座）

## 安装

```
install_skill: { local_path: "prompt-forge" }
```

或直接复制 `SKILL.md` 内容到你的 Agent skill 配置中。
